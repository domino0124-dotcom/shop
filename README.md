# 韋德機車精品｜線上商城

> 網址：https://domino0124-dotcom.github.io/shop/
> **檔名不要改、也不要搬進資料夾**，不然商城、Google 搜尋、後台會壞掉。

---

## ⭐ 網頁

| 檔案 | 做什麼 | 誰用 |
|---|---|---|
| `index.html` | **商城前台**：商品分類、搜尋、購物車、結帳（來店自取／7-11／宅配） | 客人 |
| `admin.html` | **商城後台**：訂單、新增／修改商品、從蝦皮同步商品、店面公告、Logo 店名、三陽新車分期、資料備份 | 老闆（店務帳 → 更多 → 商城後台，要登入） |

## 📦 商品資料（不用手動改）

| 檔案 | 做什麼 | 怎麼更新 |
|---|---|---|
| `products.json` | 所有商品：名稱、價格、規格、庫存、分類、圖片 | 後台上傳蝦皮匯出檔自動產生 |
| `desc.json` | 商品詳細說明 | 同上 |

**更新商品的方式：** 蝦皮賣家中心 →「批次更新」下載三個檔
（`basic_info.xlsx`、`media_info.xlsx`、`sales_info.zip`）→ 商城後台「從蝦皮同步商品」上傳 → 照後台指示完成。

## ⚙️ 設定

| 檔案 | 做什麼 |
|---|---|
| `config.json` | 商城設定：店名、運費（自取 0／7-11 60／宅配 160 起）、付款方式、連到 GAS 的網址 |

## 🛠️ 工具（網頁會自動用到，不用動）

| 檔案 | 做什麼 |
|---|---|
| `shopee-sync.js` | 後台用的轉換程式：蝦皮匯出檔 → products.json／desc.json |
| `build_products.py` | 同上的電腦版（Python），後台不能用時的備用方法 |

## 🔍 Google 搜尋用（不要刪）

| `google922fa71fc55cfb1a.html` | Google Search Console 驗證檔，刪掉會失去驗證 |

## 🖼️ 圖片

## 🗂️ 後端

訂單送到主 GAS 專案（`商城訂單.gs`），7-11 選店與物流通知也在那裡。
GAS 網址在 `config.json` 的 `gasUrl`。

## 🔄 更新流程

1. **網頁或資料（.html／.json）**：GitHub → Add file → Upload files → 同名覆蓋 → 等 1～2 分鐘
2. **GAS（商城訂單.gs）**：貼上覆蓋 → 存檔 → 管理部署作業 → 編輯 → **新版本** → 部署
